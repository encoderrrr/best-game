STARSHARD — Salvage Run: a fast arena shooter in plain static files. Fly the salvage ship, blast rogue drones, chain kills for a combo multiplier, grab shields, rapid fire and spread shot, and survive the waves.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrows, aim with the mouse, fire with click or Space. P pauses, M mutes, R restarts after a loss.
